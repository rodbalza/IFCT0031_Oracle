## Recursos online gratuitos para aprender SQL

- Oracle tiene una serie de recursos para aprender en línea, están organizados por tutoriales:
https://freesql.com/library/  

- SQL Zoo. Curso interactivo para aprender en línea y desde la propia web ejecutas las consultas.

- SQL Bolt. Curso interactivo para aprender en línea y desde la propia web ejecutas las consultas.
https://sqlzoo.net/wiki/SQL_Tutorial  
- w3schools.Curso interactivo para aprender en línea y desde la propia web ejecutas las consultas.
